## Las tres razones estructurales

La primera razón estructural es la ausencia de Game Passes. La API de Game Passes de Roblox devuelve una matriz vacía para Crunch My Butter, lo que significa que el desarrollador no ha creado ningún producto de Game Pass. Los Game Passes son el canal de distribución más común para los códigos en los simuladores de Roblox: un código desbloquea un beneficio vinculado a un Game Pass, y el desarrollador distribuye el código como herramienta de marketing.

La segunda razón estructural es la ausencia de emblemas (badges). La API de emblemas de Roblox devuelve una matriz vacía para Crunch My Butter, lo que significa que el desarrollador no ha creado ningún logro de emblema. Los emblemas son el segundo canal de distribución más común para los códigos: un código desbloquea un emblema, y el desarrollador utiliza el emblema como una forma de marcar a un jugador que ha canjeado el código.

La tercera razón estructural es la ausencia de productos de desarrollador. La API de productos de desarrollador de Roblox devuelve una matriz vacía para Crunch My Butter, lo que significa que el desarrollador no ha creado ningún artículo de compra única. Los productos de desarrollador son el tercer canal de distribución más común para los códigos: un código otorga un producto de desarrollador, que es un efecto de un solo uso, como un potenciador o un multiplicador.

En conjunto, estas tres ausencias confirman que el desarrollador no ha construido ninguna infraestructura de entrega de recompensas. Los códigos requieren al menos una de estas tres infraestructuras, y ninguna de ellas está presente. La ausencia es estructural, no estilística.
