## Por que os códigos falham ao serem resgatados

Os códigos falham ao serem resgatados por cinco motivos comuns. O primeiro motivo é a expiração: o código expirou e o desenvolvedor o removeu da lista ativa. O segundo motivo é erro de digitação: o jogador inseriu o código com um erro, um caractere faltando ou um caractere extra. O terceiro motivo é a diferenciação entre maiúsculas e minúsculas: o código exige letras maiúsculas, mas o jogador inseriu minúsculas. O quarto motivo é a restrição regional: o código só é válido em certas regiões. O quinto motivo é que o código é falso: o código não existe no sistema do desenvolvedor.

A verificação de expiração é a mais fácil de confirmar. A wiki listará a data de validade de cada código, e o jogador deve verificar a data antes de inserir o código. A restrição regional é mais difícil de verificar, e o jogador deve consultar a wiki para quaisquer notas regionais.
