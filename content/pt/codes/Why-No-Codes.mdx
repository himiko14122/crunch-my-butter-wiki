Crunch My Butter não tem códigos porque o desenvolvedor não construiu a infraestrutura para disponibilizá-los. As APIs públicas do Roblox confirmam zero Game Passes, zero emblemas e zero produtos de desenvolvedor, e a descrição oficial do jogo não menciona um sistema de resgate. Este artigo explica as razões estruturais por trás dessa ausência, por que isso é normal para novos simuladores do Roblox e o que essa ausência significa para os jogadores que buscam recompensas gratuitas. A resposta honesta é que não existem códigos para encontrar, mas a ausência também é um sinal sobre as prioridades de design do desenvolvedor.

A ausência de códigos não é um erro ou uma supervisão. É uma escolha de design deliberada que reflete o foco do desenvolvedor na progressão principal em vez de recursos adjacentes à monetização. A taxa de aprovação de 93 por cento em mais de 15.000 votos é consistente com essa escolha de design.

## As Três Razões Estruturais

A primeira razão estrutural é a ausência de Game Passes. A API de Game Passes do Roblox retorna uma matriz vazia para Crunch My Butter, o que significa que o desenvolvedor não criou nenhum produto de Game Pass. Os Game Passes são o canal de entrega mais comum para códigos em simuladores do Roblox: um código desbloqueia um benefício vinculado a um Game Pass, e o desenvolvedor distribui o código como uma ferramenta de marketing.

A segunda razão estrutural é a ausência de emblemas (badges). A API de Emblemas do Roblox retorna uma matriz vazia para Crunch My Butter, o que significa que o desenvolvedor não criou nenhuma conquista de emblema. Os emblemas são o segundo canal de entrega mais comum para códigos: um código desbloqueia um emblema, e o desenvolvedor usa o emblema como uma forma de marcar um jogador como tendo resgatado o código.

A terceira razão estrutural é a ausência de produtos de desenvolvedor. A API de Produtos de Desenvolvedor do Roblox retorna uma matriz vazia para Crunch My Butter, o que significa que o desenvolvedor não criou nenhum item de compra única. Os produtos de desenvolvedor são o terceiro canal de entrega mais comum para códigos: um código concede um produto de desenvolvedor, que é um efeito único, como um impulso ou um multiplicador.

Juntas, as três ausências confirmam que o desenvolvedor não construiu nenhuma infraestrutura de entrega de recompensas. Os códigos exigem que pelo menos uma dessas três infraestruturas esteja em vigor, e nenhuma delas está. A ausência é estrutural, não estilística.

## Por que isso é normal para novos simuladores

O padrão nos simuladores do Roblox é que os sistemas de códigos sejam adicionados após a progressão principal ser estabelecida, não no lançamento. O lançamento de um novo simulador é focado em fazer o ciclo principal funcionar, equilibrar as quatro trilhas e coletar feedback da base inicial de jogadores. O sistema de códigos é uma adição posterior que requer a construção e o teste da infraestrutura de entrega.

Outros títulos da EX10 seguem o mesmo padrão. Draw It Better! foi lançado vários anos antes do seu sistema de códigos atual, e o sistema de códigos foi adicionado em uma grande atualização de conteúdo após a experiência principal de desenho estar estável. Which Invincible Are You? e Which Soccer Player Are You? são jogos de quiz com sistemas de códigos mínimos porque jogos de quiz não possuem uma progressão profunda que se beneficie da distribuição de códigos.

## O que a ausência significa para os jogadores

A ausência de códigos significa que os jogadores não podem contar com recompensas de códigos para acelerar sua progressão. A única maneira de ganhar dinheiro no jogo é através da progressão legítima de quatro trilhas: triturar manteiga saborizada, coletar dinheiro, desbloquear manteiga melhor, atualizar o rolo, expandir a área e deixar a camada AFK multiplicar o resultado. O acúmulo é significativo, e a camada AFK foi projetada para recompensar os jogadores que se afastam no momento certo.

A ausência também significa que os jogadores não devem perder tempo procurando códigos em sites de terceiros. Toda lista de "códigos funcionando" em um site de terceiros é um gancho de clickbait para gerar tráfego de anúncios ou uma reciclagem de códigos genéricos de simuladores que não funcionam. A resposta honesta é que não há códigos para encontrar, e o tempo gasto procurando é tempo que poderia ser gasto na progressão legítima.

A ausência também é um sinal sobre as prioridades de design do desenvolvedor. A taxa de aprovação de 93 por cento é consistente com um foco na experiência principal, e o desenvolvedor está deixando a progressão falar por si mesma em vez de adicionar um sistema de recompensas por código. Jogadores que valorizam uma progressão justa em vez de atalhos de microtransações acharão Crunch My Butter uma mudança refrescante em relação aos simuladores típicos do Roblox.

## Os Três Canais Alternativos de Recompensas Gratuitas

Mesmo sem códigos, o jogo possui três canais alternativos de recompensas gratuitas. O primeiro é a camada de ganhos offline, que credita dinheiro ao saldo do jogador enquanto ele está ausente. A taxa offline é uma função da configuração atual do jogador de sabor de manteiga, atualização do rolo e expansão da área.

A segunda alternativa é a própria progressão do sabor da manteiga. O próximo sabor de manteiga é uma "recompensa gratuita" no sentido de que o jogador a ganha através da progressão legítima, e o novo sabor multiplica o dinheiro por trituração. O acúmulo é significativo, e o jogador não precisa de um código para acessar a próxima manteiga.

A terceira alternativa é a própria experiência ASMR. A satisfação visual de quebrar a manteiga, a satisfação auditiva do estalo da casca e a filosofia de design focada em ASMR são todas recompensas que não exigem um código para serem desbloqueadas. O jogador que valoriza a experiência sensorial achará a progressão gratificante, independentemente da existência de códigos.

## Como seria um código funcional

Um código funcional em Crunch My Butter seguiria o padrão padrão do Roblox: uma curta sequência alfanumérica, geralmente de seis a dez caracteres, que o jogador cola em uma caixa de resgate dentro do jogo ou na página oficial de resgate de códigos do Roblox. A recompensa geralmente é uma quantia fixa de moeda do jogo, um pequeno impulsionador ou um item cosmético, e o código é de uso único por conta.

O formato de um código funcional é o mesmo na maioria dos simuladores do Roblox, e o código de Crunch My Butter seria o mesmo se o desenvolvedor lançasse um. A wiki rastreia o padrão do Roblox para que o jogador saiba o que procurar quando o desenvolvedor eventualmente lançar o primeiro código, e para que o jogador possa identificar rapidamente a diferença entre um código real e um falso.

## Por que a wiki não publica uma lista de códigos
