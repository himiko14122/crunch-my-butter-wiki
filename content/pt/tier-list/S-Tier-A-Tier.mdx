## A Prioridade Padrão

A prioridade padrão é S tier (manteiga) > A tier (rolo) > B tier (área) > C tier (manual). A prioridade é a base da lista de tiers no wiki. O princípio é o mesmo independentemente do sabor de manteiga atual ou da tier do rolo do jogador, conforme confirmado pelo snapshot da API ao vivo de 26 de julho de 2026.

A prioridade padrão se inverte quando o rolo é o gargalo. O jogador que reconhece a regra de substituição investe no A tier quando o A tier é o gargalo, e o jogador que ignora a regra de substituição investe no S tier quando o S tier não é o gargalo.

## O Reconhecimento do Gargalo

O reconhecimento do gargalo é o teste que determina se o S tier ou o A tier é o gargalo. O teste é simples: se o chão estiver cheio de manteiga não processada, o A tier (rolo) é o gargalo. Se o rolo estiver varrendo o chão entre respawns e não houver manteigas não processadas, o S tier (manteiga) é o gargalo.

O reconhecimento do gargalo é a base da estrutura de decisão. O jogador que segue o reconhecimento investe na tier que resolve o gargalo, que é o maior ganho marginal possível. O jogador que ignora o reconhecimento investe em tiers arbitrárias, o que produz um acúmulo mais lento.

O reconhecimento do gargalo é qualitativo porque a cobertura exata do rolo não é publicada. O princípio é que o rolo deve ser capaz de acompanhar a taxa de respawn da manteiga, e o chão deve estar vazio de manteiga não processada quando o rolo estiver varrendo. O reconhecimento é a defesa do jogador contra o superinvestimento na tier errada.

O efeito multiplicador é a base do ciclo de acúmulo. O multiplicador do S tier se aplica a cada passada do rolo, enquanto o multiplicador do A tier se aplica a cada processamento de manteiga.
